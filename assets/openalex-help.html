AreaDay 初次设置

获取你的 OpenAlex API Key

免费 Key 可以提高跨学科论文检索和公开全文获取的可用额度。完成后请回到 AreaDay 打开的配置文件，将 Key 填入指定位置并保存；保存后告诉 Agent「填好了」，它会自动验证并继续。

1

打开 OpenAlex API 设置

登录或免费创建 OpenAlex 账户，然后进入 API 设置页面。

打开 OpenAlex Settings ↗
2

复制完整的 API Key

在设置页面复制完整 Key，不要复制变量名、引号或其他说明文字。

3

把 Key 粘贴到配置文件里

AreaDay 会帮你打开配置文件 credentials.ini（如果没有自动打开，就用任意文本编辑器打开它）。把 Key 粘贴到 api_key = 后面，保存文件即可。不需要在终端里输入任何东西，也没有程序在等你。

保存后回到对话里告诉 Agent「填好了，继续」，它会检查 Key 是否有效。

默认位置：本 Skill 目录下的 data/credentials.ini。AreaDay 只从这个文件读取 Key。

本页面不会读取、接收或保存你的 Key。Key 只写入这台电脑上的 AreaDay 配置文件。
