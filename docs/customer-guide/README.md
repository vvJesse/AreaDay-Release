# AreaDay 用户安装指南维护说明

本目录保存面向购买用户的安装与基本使用指南。这里是指南的唯一维护源，不要分别手改桌面副本、PDF 或网页文案。

## 文件

- `AreaDay-安装和使用指南.md`：可编辑的正式正文，也是 PDF 的唯一内容来源。
- `AreaDay-安装和使用指南-v<版本号>.pdf`：交付给用户的版本化 PDF。
- `../../scripts/build_customer_guide_pdf.py`：根据正文生成 PDF。

`references/customer-installation.md` 是 Skill 内部给 AI 助手使用的安装规范，不是用户指南。两者描述的安装行为必须一致，但面向用户的表达只在本目录维护。

## 版本规则

指南首页必须写明 `适用版本：AreaDay vMAJOR.MINOR.PATCH`。PDF 文件名由生成脚本自动读取这个版本号，不要手工改 PDF 文件名。

只修改措辞、排版或错别字时，可以保持适用版本不变并更新日期。安装包、支持平台、安装流程或产品行为发生变化时，必须同步更新适用版本。

## 每次发布必须逐项更新

1. 首页的适用版本和更新日期。
2. macOS 安装包名称与 R2 直接下载链接。
3. Windows 安装包名称与 R2 直接下载链接。
4. GitHub 仓库链接与最新 Release 链接。
5. 安装消息模板：GitHub 链接、`帮我安装这个 Skill。`、本地安装包完整路径。
6. 许可证文件的交付方式：与安装消息放在同一条消息中，拖拽上传后再发送。
7. 当前支持的系统与不支持的平台。
8. Codex、WorkBuddy 实际使用的 Skill 调用方式。
9. 首次建立词表的真实步骤，尤其是 OpenAlex 说明页和 `credentials.ini` 打开的准确时机。
10. 视频教程地址及其内容是否与当前版本一致。
11. 常见问题、隐私说明及产品实际行为。

## 生成 PDF

在仓库根目录运行：

```bash
python3 scripts/build_customer_guide_pdf.py
```

脚本会在本目录生成 `AreaDay-安装和使用指南-v<版本号>.pdf`。

## 交付前检查

1. 逐一打开 macOS、Windows、GitHub、视频教程链接。
2. 检查安装消息是否可以直接复制使用，且许可证文件的上传顺序明确。
3. 对照当前产品实际操作，确认 OpenAlex、校准页面和工作台的出现顺序。
4. 将 PDF 全部页面渲染成图片，检查中文字体、分页、长链接、代码框和页脚。
5. 确认 PDF 首页和文件名中的版本号一致。
6. 将最终 PDF 同步到用户下载位置和公开网页；不要从临时目录交付。

完成以上检查后，才能把新 PDF 作为该版本的正式用户指南。
